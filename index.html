Court-Grade Form Automation
Without Vendor Lock-In

FormGuide is a free, serverless Python toolkit that converts any official federal or state court PDF into reusable JSON Schemas, merging local profile data with 100% vector point precision.

🚀 Get Started on GitHub Read Documentation
⚡

Instant PDF Field Mapper

Auto-detects AcroForm widgets and visual underline geometries on any downloaded court PDF in under 2 seconds.

python3 -m formguide.form_mapper --input court_form.pdf
🔒

100% Local-First Privacy

Keep sensitive litigant data (income, medical records, SSNs) entirely local in structured JSON profiles. Zero cloud database risk.

profiles/user_profile.json
🏛️

Court-Grade Vector Overlay

Merges native AcroForm data and ReportLab vector typography directly onto official court templates without pixel distortion.

python3 -m formguide.filling_engine

Quickstart CLI Integration

# 1. Clone the repository git clone https://github.com/Precedent-Systems/FormGuide.git cd FormGuide # 2. Fill a court PDF using local profile JSON python3 -m formguide.filling_engine \ --template templates/js_044.pdf \ --schema schemas/federal/us_district_court_js044.json \ --profile profiles/annika_eriksson_profile.json \ --output Filled_JS44_Civil_Cover_Sheet.pdf
